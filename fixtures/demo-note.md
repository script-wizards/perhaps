# perhaps demo note

Copy this note into a vault with the perhaps plugin enabled. In reading view
the block below becomes a live roller; the "Roll a table" command finds it
from anywhere.

```perhaps
title
  Tavern Trouble

output
  [patron] {argues with|challenges|buys a round for} [patron] over {2-12} silver
  the barkeep needs [errand] ^2

patron
  a nervous scribe
  an off-duty guard ^2
  a {cheerful|sullen} dwarf prospector

errand
  2d6 rats cleared from the cellar
  a letter delivered to [patron]
  a missing cask found before nightfall
```
